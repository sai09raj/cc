# Case study: Task 20 MV-20 (Bramhall Colliery mine ventilation), fourth stump, passed at v1

**Result:** 21, 35 and 14 (Model A = claude-opus-4-8), all completed in 22–29 min, all below 50 at the **first version**. Scores were validated afterwards: each run's values reproduce from its own drawing reading, and the strict re-grade gives 20.7, 35.1 and 13.5.

## 1. The task

- **Platform entry:** Domain **Mechanical Engineering**. Mining is not in the platform's fixed list, so check that list in 00-START first. Subdomain: "Mine Ventilation Engineering — underground airway network analysis (Atkinson resistance, fan duty point, regulators)".
- **Network:** one mine level with 12 nodes (shaft bottoms PB and UB, junctions J1–J10) and 16 airways, each made of 2 roadway sections:
  - intakes I1–I4, W1, C1, E1;
  - returns W2, C2, E2, T1, R1–R3;
  - crosscuts X1 (door D1) and X2 (stopping ST-7).
- **Physics (all stated on the data sheet):**
  - section resistance R = k L per / A³ from 5 roadway profiles, with p = R Q|Q|;
  - regulators R = ρ/(2 (0.65 A)²), in series;
  - a damaged stopping replaced by brattice adds 3.5 N s²/m⁸;
  - fan curve p = a − b1 Q − b2 Q² (main fan at −5/0/+5 deg, or standby);
  - shaft resistances for DS and US;
  - node static pressure relative to surface, with p(PB) and p(UB) spelled out;
  - face airflow = flow in W2/C2/E2, with a 30.0 m³/s statutory minimum.
- **Packet:** 3 pages: data sheet, night-shift log, ventilation plan (a plain RGB image).
- **Log state at 08:00 (every run solved all of it):**
  - main fan tripped at 04:10 and held on standby at 06:30, so the **standby** curve applies; the requested +5 deg blade change was never made;
  - REG-E opened to 3.6 m² and its reset deferred (07:55);
  - REG-T cut to 1.0 m²;
  - door D1 propped open, so X1 carries air;
  - ST-7 damaged and bratticed, so X2 carries air.
- **Memo finding:** the C face gets 28.60 m³/s, below 30.0. REG-C was tuned from 2.0 to 1.8 m² to produce it.

## 2. How it was built (one pass, in this order)

1. **Model:** `net.py` holds the single source of truth; `vent.py` is a Newton solver on node pressures with the fan branch inverted analytically; `state.py` holds the 08:00 state and the normal state.
2. **Misread simulation:** `pick.py` swaps every pair of adjacent sections at every node, and adds log slips (fan, REG-E, REG-T, X1 shut, ST-7 intact, no brattice).
   - It showed that two of my planned corners (J10 I4/T1, J4 W2/R1) do nothing: those airways are **in series**, so a swap changes no flow. Always simulate before drawing.
3. **Data tuning for the corners:** widened two pairs into the 20–35 % band (X1 400 → 470, R2 410 → 440).
4. **Graded set:** chosen by the sensitivity greedy, 24 numeric rows at weight 4 plus 15 points of non-numeric rows.
   - Series duplicates were excluded so no value is graded twice: R1 = W2, I1 = fan Q, T1 = I4.
   - Every trap simulated to 17–21 and every log slip to 13 or below (strict).
5. **Drawing:** four crossed corners, spread across the plan, using the exact geometry in 16-CASE-STUDY section 3:
   - J2: C1/I3, P2 360/450;
   - J5: C2/R2, P5 350/440;
   - J7: W1/X1, P3 380/470;
   - J9: E1/X2, P4 280/360.

   Two layout passes fixed overlapping route tags, station numbers, the regulator label and the stopping label. Every leader was checked in code to land on its own section.
6. **Packet:** data sheet and log generated from `net.py`; PDF metadata stripped; image flattened to RGB (#100); leak check passed.
7. **Rubric, prompt and Ideal Flow:** generated by `build.py` from key.json. Memo rows grade only the citation where the state is graded in a results row (#99), and the parentheticals were removed from the D1 and ST-7 memo rows (atomicity).
8. **Gate:** `tools/gate.py` plus an **independent re-solve**, using numbers parsed from the data sheet text and section lengths read off the plan image, matched every graded value to 1e-13. The gate also caught an ungraded number (E face 44.66) in the Execute Ideal Flow, which was fixed.

## 5. Do and Don't (this task)

- **Do** run the whole recipe at v1:
  1. model;
  2. misread simulation;
  3. sensitivity-chosen rubric;
  4. crossed corners;
  5. gate;
  6. independent re-solve;
  7. entry.
- **Do** simulate every planned corner before drawing it. Swaps between airways in series change nothing.
- **Do** exclude series-duplicate quantities from the graded set.
- **Do** create one real, physically consistent finding for the memo (a face below its statutory minimum) by tuning an input (a regulator opening), and check that the misreads move it.
- **Do** consider a crowded junction with an equal-length pair from different routes as an extra natural trap.
- **Do** validate scores after the runs (gate section F): reproduce each run from its own reading, then re-grade with the printed ranges.
- **Don't** pick a domain that isn't on the platform's fixed list. Use the closest entry and put the specialism in the subdomain.
- **Don't** put a number in the Ideal Flow that no criterion grades (the gate's B6 check).
- **Don't** treat the score simulation as proof of a stump. It predicts grading, not whether the model will misread (gate section on simulation limits).
